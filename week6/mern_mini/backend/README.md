# MERN Mini App

## Overview

MERN Mini App is a full-stack web application developed using the MERN stack:

* MongoDB
* Express.js
* React.js
* Node.js

This project demonstrates the implementation of a modern web application with frontend and backend integration, REST APIs, database management, and modular architecture.

The application is suitable for learning:

* MERN stack development
* REST API creation
* Frontend-backend communication
* Database operations
* Authentication concepts
* CRUD functionality

---

## config/

---

## server.js

Main entry point for the backend server.

### Responsibilities

* Initialize Express server
* Connect MongoDB database
* Register middleware
* Handle API routes
